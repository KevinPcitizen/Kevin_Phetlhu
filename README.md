# Network Penetration testing case study
- This case study covers the standard of ethical hacking methods , tools of workflow and analysis on targeted environments.

# Case study overview and stages 
- Stage 1 : Networking scanning covers tools such as Nmap in which targets IP address hosts, open TCP ports and running services.
- Stage 2 : Vulnerability identification is conducted through look up tools such as Metasploit frame work in which targets the backdoor vulnerability such as Vsftpd.
- Stage 3 : Payload & Handler configuration enables the handler to set up a local host by identifying first using this command Ip a or ifconfig. A selection insetting up the payload by loading module e.g exploit/unix/ftp/vsftpd_243_backdoor to target an unanthuenticated command.
- Stage 4 : Post - exploitation this refer to successful execution of retrieving a password to an account.
